Parte 1: 20 etiquetas de HTML

Las etiquetas 1 a 10 (html, head, title, style, body, header, nav, a, main y section) forman la estructura de esta página y están explicadas en los comentarios del código. Las otras diez van aquí abajo con su ejemplo.

11 <h1>

Tipo: encabezado. Para qué sirve: es el TÍTULO más importante de la página. Existen del h1 al h6, y el h1 es el de mayor jerarquía.

<h1>Mi cuaderno de HTML y CSS</h1>
EJEMPLO EN VIVO:

Título principal

12 <p>

Tipo: párrafo. Para qué sirve: escribir un PÁRRAFO de texto normal.

<p>Me gusta aprender a programar.</p>
EJEMPLO EN VIVO:

Me gusta aprender a programar.

13 <img>

Tipo: imagen. Para qué sirve: mostrar IMÁGENES. Usa src (de dónde sale la imagen) y alt (texto por si no carga). No lleva cierre.

<img src="logo.png" alt="Logo de mi página">
EJEMPLO EN VIVO:
14 <article>

Tipo: artículo (contenido independiente). Para qué sirve: agrupar un bloque que tiene sentido por sí solo, como una noticia, una publicación o una tarjeta.

<article> <h3>Aviso</h3> <p>Mañana no hay clase.</p> </article>
EJEMPLO EN VIVO:

Aviso

Mañana no hay clase.

15 <ul>

Tipo: lista desordenada. Para qué sirve: hacer una LISTA SIN ORDEN, con puntos (viñetas).

<ul> <li>Laptop</li> <li>VS Code</li> </ul>
EJEMPLO EN VIVO:
  • Laptop
  • VS Code
  • Café
16 <li>

Tipo: elemento de lista. Para qué sirve: es CADA RENGLÓN de una lista. Va dentro de un <ul> o de un <ol> (lista numerada).

<ol> <li>Abrir VS Code</li> <li>Escribir el código</li> </ol>
EJEMPLO EN VIVO:
  1. Abrir VS Code
  2. Escribir el código
  3. Guardar con Cmd + S
17 <table>

Tipo: tabla de datos. Para qué sirve: mostrar información en FILAS y COLUMNAS. Se arma con <tr> (fila), <th> (encabezado) y <td> (celda).

<table> <tr><th>Materia</th><th>Día</th></tr> <tr><td>Programación</td><td>Lunes</td></tr> </table>
EJEMPLO EN VIVO:
MateriaDía
ProgramaciónLunes
Diseño webMiércoles
18 <form>

Tipo: formulario. Para qué sirve: agrupar los CAMPOS donde el usuario escribe datos para enviarlos. Adentro van los <input> y el <button>.

<form> <input type="text" placeholder="Nombre"> <button>Enviar</button> </form>
EJEMPLO EN VIVO:
19 <input>

Tipo: campo de entrada. Para qué sirve: un CAMPO donde el usuario escribe. El atributo type cambia el tipo: text, email, password, etc. No lleva cierre.

<input type="text" placeholder="Escribe aquí"> <input type="password" placeholder="Contraseña">
EJEMPLO EN VIVO:
20 <button>

Tipo: botón. Para qué sirve: crear un BOTÓN que se puede presionar para hacer una acción o enviar un formulario.

<button>Enviar tarea</button>

Parte 2: 20 propiedades de CSS

Todas estas propiedades están escritas dentro de la etiqueta <style> en el <head>, cada una con su comentario. Aquí abajo está qué hace cada una, su sintaxis y un ejemplo.

1 color

Qué hace: cambia el COLOR de las letras.

/* sintaxis: selector { color: valor; } */ .m-color { color: #2B4C7E; } /* azul */
EJEMPLO EN VIVO:

Estas letras son azules.

2 background

Qué hace: pone el FONDO de un elemento: color, imagen o degradado, en una sola línea.

/* sintaxis: selector { background: valor; } */ .m-fondo { background: linear-gradient(135deg, #2F6F4F, #2B4C7E); }
EJEMPLO EN VIVO:
Fondo con degradado
3 background-size

Qué hace: controla el TAMAÑO de la imagen o patrón de fondo.

/* sintaxis: selector { background-size: valor; } */ background-size: cover; /* cubre todo */ background-size: contain; /* se ve completa */ background-size: 12px 12px; /* ancho y alto fijos */
EJEMPLO EN VIVO (mismo patrón, distinto tamaño):
12px
30px
4 font-family

Qué hace: cambia el TIPO DE LETRA.

/* sintaxis: selector { font-family: fuente1, fuente2; } */ .m-serif { font-family: Georgia, serif; }
EJEMPLO EN VIVO:

Texto en letra de código

Texto en Georgia

5 font-size

Qué hace: cambia el TAMAÑO de la letra.

/* sintaxis: selector { font-size: valor; } */ .m-chica { font-size: 12px; } .m-grande { font-size: 28px; }
EJEMPLO EN VIVO:

Letra de 12px

Letra de 18px

Letra de 28px

6 font-weight

Qué hace: cambia el GROSOR de la letra.

/* sintaxis: selector { font-weight: valor; } */ font-weight: 400; /* normal */ font-weight: 700; /* negrita */
EJEMPLO EN VIVO:

Grosor normal (400)

Grosor negrita (700)

7 text-align

Qué hace: ALINEA el texto a la izquierda, al centro o a la derecha.

/* sintaxis: selector { text-align: left|center|right|justify; } */
EJEMPLO EN VIVO:

Izquierda

Centro

Derecha

8 text-transform

Qué hace: pasa el texto a MAYÚSCULAS o minúsculas sin cambiar el HTML.

/* sintaxis: selector { text-transform: valor; } */ text-transform: uppercase; /* TODO MAYÚSCULAS */ text-transform: capitalize; /* Cada Palabra */
EJEMPLO EN VIVO:

escrito en minúsculas

ESCRITO EN MAYÚSCULAS

cada palabra con mayúscula

9 text-decoration

Qué hace: pone o quita LÍNEAS al texto. Sirve mucho para quitar el subrayado de los links.

/* sintaxis: selector { text-decoration: valor; } */ text-decoration: none; /* sin línea */ text-decoration: line-through; /* tachado */
EJEMPLO EN VIVO: Link sin subrayado

Texto subrayado

Texto tachado

10 margin

Qué hace: deja espacio AFUERA de la caja para separarla de lo demás.

/* sintaxis: selector { margin: valor; } */ margin: 1.2rem; /* los 4 lados */ margin: 0 auto; /* centra la caja */
EJEMPLO EN VIVO (la línea punteada es el contenedor):
margin: 1.2rem
11 padding

Qué hace: deja espacio ADENTRO de la caja, entre el borde y el texto.

/* sintaxis: selector { padding: valor; } */ padding: 1.8rem; /* los 4 lados */ padding-top: 1rem; /* solo arriba */
EJEMPLO EN VIVO:
padding: 1.8rem
12 border

Qué hace: dibuja un BORDE. Lleva tres valores: grosor, estilo y color.

/* sintaxis: selector { border: grosor estilo color; } */ border: 3px dashed #2F6F4F; /* punteado verde */ border: 1px solid black; /* línea continua */
EJEMPLO EN VIVO:
Caja con borde punteado
13 border-radius

Qué hace: REDONDEA las esquinas. Con 50% se vuelve círculo.

/* sintaxis: selector { border-radius: valor; } */ border-radius: 16px; /* esquinas redondas */ border-radius: 50%; /* círculo */
EJEMPLO EN VIVO:
16px
50%
14 display

Qué hace: cambia CÓMO SE ACOMODA un elemento en la página.

/* sintaxis: selector { display: block|inline|flex|grid|none; } */ display: block; /* ocupa todo el ancho */ display: inline; /* solo lo que mide */
EJEMPLO EN VIVO (block vs inline): block: ocupo todo el renglón inline inline
15 flex-direction

Qué hace: en un contenedor flex, pone a los hijos en FILA (row) o en COLUMNA (column).

/* sintaxis: selector { flex-direction: row|column; } */ .m-columna { display: flex; flex-direction: column; }
EJEMPLO EN VIVO:

3
16 justify-content

Qué hace: en un contenedor flex, REPARTE el espacio de forma horizontal (si es fila).

/* sintaxis: selector { justify-content: valor; } */ justify-content: center; /* al centro */ justify-content: space-between; /* a los extremos */
EJEMPLO EN VIVO:

B
17 align-items

Qué hace: en un contenedor flex, alinea a los hijos de forma VERTICAL (si es fila).

/* sintaxis: selector { align-items: center|start|end|stretch; } */ .m-centrado-v { display: flex; align-items: center; }
EJEMPLO EN VIVO:
alto
centrado
18 box-shadow

Qué hace: le pone SOMBRA a la caja para que se vea con profundidad.

/* sintaxis: box-shadow: ejeX ejeY desenfoque color; */ .m-sombra { box-shadow: 6px 6px 12px rgba(0,0,0,.25); }
EJEMPLO EN VIVO:
Caja con sombra
19 transition

Qué hace: hace que un cambio de estilo pase POCO A POCO y no de golpe.

/* sintaxis: transition: propiedad duración; */ .m-transicion { transition: background-color .4s; } .m-transicion:hover { background-color: #2F6F4F; }
